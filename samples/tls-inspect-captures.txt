# Differences to expect on the Windows 11 lecture machine (not captured here):
# - Protocol: PowerShell 7 on Windows 11 usually shows Tls13 (Schannel). Windows
#   PowerShell 5.1 (.NET Framework) usually shows Tls12. Check $PSVersionTable first.
# - SAN is formatted by Windows as "DNS Name=www.depaul.edu".
# - Windows PowerShell 5.1 wraps failures as "Could not establish trust
#   relationship for the SSL/TLS secure channel"; PowerShell 7 shows the
#   messages above.
# - incomplete-chain.badssl.com usually PASSES on Windows and macOS because the
#   OS downloads the missing intermediate (AIA fetching). Firefox and OpenSSL
#   fail it. Test chains with a strict client, not just your own browser.
